# Сундучки

Карточная игра против компьютера для Windows. Нужно первым собрать четыре «сундучка», то есть четыре набора по четыре карты одного достоинства. Приложение написано на C# (WPF) по паттерну MVVM.

## Правила

- Колода: 36 карт (от 6 до туза, 4 масти, 9 достоинств).
- В начале каждому игроку раздаётся по 7 карт, остальные лежат в колоде.
- В свой ход игрок спрашивает соперника о достоинстве: «Есть ли у тебя дамы?». Спрашивать можно только о том достоинстве, которое есть у самого игрока на руке.
- Если у соперника есть такие карты, он отдаёт все карты этого достоинства, и спрашивающий ходит снова.
- Если таких карт нет, игрок берёт одну карту из колоды. Если взятая карта оказалась того достоинства, о котором он спрашивал, ход остаётся у него. Иначе ход переходит сопернику.
- Как только у игрока набирается четыре карты одного достоинства, они откладываются в сторону и приносят ему один сундучок. Проверка идёт после каждой передачи карт и после каждого взятия из колоды.
- Если у игрока кончились карты, он берёт одну из колоды. Если колода тоже пуста, он пропускает ход.
- Побеждает тот, кто первым соберёт 4 сундучка. Если ходов больше нет (колода и руки пусты), побеждает тот, у кого сундучков больше. При равенстве объявляется ничья.

Недопустимые ходы заблокированы: кнопка недоступна, а на экране написана причина.

## Режим игры

Человек против компьютера. Карты бота скрыты, а в журнале событий видно, что и о чём он спрашивал и что получил. Бот работает (пока) в одном режиме сложности:

- простой: спрашивает случайное достоинство из своей руки;

При достаточном времени и возможностях будет реализован еще один режим:
- умный: запоминает, о чём спрашивал игрок, и использует это при выборе вопроса.

## Технологии

- C# и XAML
- [WPF / Avalonia]
- Паттерн MVVM
- [ReactiveUI / R3]
- Асинхронность: бот «думает» в фоновой задаче, сохранение и загрузка партии идут асинхронно, интерфейс не зависает
- Сторонних графических движков нет
